# Haotian Xie — Academic Homepage

This repository contains the GitHub Pages site for Haotian Xie, featuring research in Operations Research, Complex Systems, logistics, supply chains, and data-driven decision making.

The site uses the structure and layout of [SimpleAcademicHomepage](https://github.com/ShenzheZhu/SimpleAcademicHomepage): a dependency-free Cargo-inspired single-page layout with a fixed sidebar, responsive mobile navigation, page transitions, publication grouping, and publication filtering.

## Content files

- `index.html` — site shell, metadata, sidebar, navigation, and mobile controls
- `pages/home.html` — home summary
- `pages/about.html` — biography, research interests, experience, education, and contact information
- `pages/publications.html` — publications and links
- `pages/selected-publications.html` — selected publications shown below the homepage content
- `pages/misc.html` — awards and academic services
- `style.css` — template styling
- `script.js` — template navigation and interactions

The site is static and deploys directly from the repository root through GitHub Pages.
